# Support

## Getting help

- **Using a template:** start with that repository's README.
- **Found a bug or have an idea?** Open an issue in the repository it's about.
- **Found a security vulnerability?** Don't open an issue. Follow the [security policy](SECURITY.md).

These are personal open source projects maintained in spare time, so responses are best effort.

## Supporting the work

If the templates are useful to you, please consider [sponsoring on GitHub](https://github.com/sponsors/stphnwlsh). Sponsorship helps keep every template current with each .NET release.
